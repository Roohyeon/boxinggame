# 🥽 AI 복싱 스파링 VR

👉 **바로 하기: https://roohyeon.github.io/boxinggame/** (크롬 추천, 웹캠 필요)

웹캠으로 손과 얼굴 위치를 읽어서, **3D 링 안에서 1인칭으로** AI 로봇 펀치봇과 복싱하는 게임이에요.
(2D 버전은 `../boxing` 폴더에 그대로 있어요)

| 동작 | 결과 |
|---|---|
| ✊ 주먹 쥐고 빠르게 뻗기 | 펀치! 파란 글러브가 화면 안쪽으로 쭉 뻗어요 |
| 🎯 초록 고리(빈틈)를 치기 | 데미지 5 (3콤보부터 +2) |
| 🧤 빨간 장갑으로 막은 곳을 치기 | "막힘!" 데미지 없음 |
| ⚠️ 예고 때 두 주먹을 얼굴 앞에 | 가드! 상대가 비틀거려요 |
| ↔️ 예고 때 고개를 재빨리 옆으로 빼거나 숙이기 | 회피! 상대가 비틀거려요 |
| 💫 비틀거리는 상대를 치기 (노란 고리) | 카운터! 데미지 12 |
| 👀 고개를 좌우·위아래로 움직이기 | 링 안 시점이 따라 움직여요 |

## 화면 구성

- **화면 전체가 게임**: 3D 경기장이 브라우저 창을 가득 채워요. **[⛶ 전체화면]**을 누르면 탭·주소창까지 숨겨요. (나올 때는 `Esc`)
- **맨 위 고정**: 내 체력 | 라운드·시간 | 펀치봇 체력. 그 아래에 안내 글자와 콤보·가드·회피·최고 기록.
- **왼쪽 아래 도구 막대**: 카메라 켜기, 시합 시작, 끄기, 난이도, 소리, 전체화면, 진단
- **오른쪽 아래 작은 웹캠 창**: 손 점과 얼굴 상자가 보여요. 피하는 중이면 얼굴 상자가 초록색이 돼요.
- **[진단]**: 누르면 분석 속도, 손·머리 상태가 왼쪽 아래에 나와요. (잘 안 될 때 원인 찾기용)
- **3D 링**: 파란 매트, 로프 3줄, 코너 기둥(내 쪽 파랑 / 펀치봇 쪽 빨강), 스포트라이트, 관중석과 카메라 플래시
- **펀치봇**: 통통 튀는 스텝, 맞으면 고개가 돌아가고, 몸통을 맞으면 허리를 숙여요. KO되면 뒤로 쓰러져요.
- **내 글러브**: 화면 아래 파란 글러브 두 개가 내 손을 따라 움직여요.
- **맞으면**: 화면이 흔들리고, 가장자리가 빨개지고, 잠깐 흐려져요.

## 경기 규칙

- **연습**: 카메라를 켜면 바로 연습해요. 상대가 공격도 하지만 체력은 안 깎여요.
- **시합**: 3라운드 × 60초, 라운드 사이 4초 휴식 (내 체력 +15)
- **끝**: 체력 0이면 KO. 다 버티면 남은 체력이 많은 쪽이 판정승.
- **점수** = 준 데미지 + 가드 × 3 + 회피 × 4 + 남은 체력 + 승리 50 (KO 승리면 +30 더)
- **등급**: 0~59 체육관 연습생 · 60~119 아마추어 복서 · 120~179 프로 복서 · 180 이상 챔피언
- 난이도(쉬움/보통/어려움)는 2D 버전과 같아요.

## 실행 방법

1. 터미널에서 이 폴더(`boxing-vr`)로 이동해요.
2. 로컬 서버를 켜요.
   ```
   python -m http.server 5502
   ```
3. 크롬 주소창에 직접 **http://127.0.0.1:5502** 를 입력해요.
4. **[카메라 켜기]** → 카메라 허용 → 연습해 보고 **[시합 시작]**
5. 끝낼 때는 터미널에서 `Ctrl + C`

처음 한 번은 인식 프로그램과 3D 도구를 내려받느라 몇 초 걸려요. (인터넷 필요)

> 💡 카메라에서 한 걸음 떨어져서 **얼굴과 두 손이 같이 보이게** 서면 잘 돼요.
> 피하기를 하니까 주변에 부딪힐 물건이 없는지 확인해 주세요.

## 잘 안 될 때 조절하기 (`gestures.js`)

**[진단]** 버튼을 눌러 나오는 글을 보면서 고쳐요.

| 문제 | 고칠 곳 |
|---|---|
| 펀치가 잘 안 나가요 | `PUNCH.minSpeed`(예: `4`), `PUNCH.minGrowth`(예: `1.5`) 낮추기 |
| 가만히 있어도 펀치가 나가요 | 위 두 숫자 높이기 |
| 가드해도 자꾸 맞아요 | `GUARD.maxY`(예: `0.7`), `GUARD.maxGapX`(예: `0.4`) 키우기 |
| 피했는데 맞았대요 | `HEAD.dodgeX`(지금 `0.06`), `HEAD.duckY`(지금 `0.05`) 낮추기 |
| 가만히 있는데 피한 걸로 돼요 | `HEAD.dodgeX`, `HEAD.duckY` 높이기 |
| 시점이 너무 많이/적게 움직여요 | `HEAD.moveX`, `HEAD.moveY` 바꾸기 |
| 화면이 버벅여요 | 화질은 "가벼움"으로 고정돼 있어요. 다른 탭·프로그램을 닫아요. 더 좋은 컴퓨터면 `main.js`의 `QUALITY.light`를 `QUALITY.normal`로 |
| 피하기가 어려워요 | `HEAD.dodgeX`, `HEAD.duckY`를 더 낮추거나, `HEAD.memoryMs`(피한 걸 기억하는 시간)를 늘려요 |

## 파일 설명

| 파일 | 하는 일 |
|---|---|
| `index.html` | 화면 틀, Three.js 주소(importmap) |
| `style.css` | 꾸미기: 체력바, 작은 웹캠 창, 맞았을 때 효과 |
| `main.js` | 카메라, 손·얼굴 인식, 펀치·가드·회피 판정, 경기 진행 |
| `scene.js` | 3D 무대: 링, 조명, 관중석, 내 글러브, 불꽃, 시점 |
| `robot.js` | 3D 펀치봇 모양과 움직임, 맞은 곳 찾기 |
| `opponent.js` | 펀치봇 두뇌: 자세 → 예고 → 공격 → 비틀, 자주 맞는 곳 기억 |
| `gestures.js` | 판단 기준: 주먹, 펀치 힘, 가드, 머리 피하기 |
| `sound.js` | 효과음 (2D 버전과 같아요) |

## 원리 (궁금한 사람용)

- **글러브 위치**: 웹캠 속 주먹 위치를 거울처럼 뒤집어서 3D 화면의 같은 자리에 글러브를 둬요.
  주먹이 카메라에 다가오면(주먹 폭이 커지면) 글러브도 화면 안쪽으로 들어가요.
- **맞은 곳 찾기**: 내 눈(카메라)에서 글러브 쪽으로 보이지 않는 광선을 쏴서,
  펀치봇의 머리(왼쪽/오른쪽 절반)나 몸통에 닿는지 확인해요.
- **시점과 피하기**: 얼굴 상자 가운데를 따라 3D 카메라를 옮겨요.
  "평소 자세"는 천천히 따라오기 때문에, 재빨리 움직인 만큼만 피하기로 쳐요.
  주먹이 도착하기 0.4초 전부터 한 번이라도 피하는 자세였으면 피한 걸로 쳐요. (예고 표시가 초록 "✔ 회피 자세!"로 바뀌어요)
  펀치봇은 공격을 예고할 때 내 얼굴 위치를 노려 두고 그쪽으로 주먹을 날려요.

## 개인정보

- 영상은 브라우저 안에서만 분석해요. 서버로 보내거나 저장하지 않아요.
- 얼굴은 위치만 읽어요. 누구인지 알아보지 않아요.
- 마이크는 쓰지 않아요. 최고 기록 숫자만 이 브라우저에 저장해요.
